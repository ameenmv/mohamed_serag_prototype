# بروتوتايب محمد سراج - E-Commerce

بروتوتايب كامل ومترابط لمتجر محمد سراج للأجهزة الكهربائية والأدوات المنزلية.

## الصفحات

| الملف | الصفحة | الوصف |
|-------|--------|-------|
| `index.dc.html` | الرئيسية (Landing) | الصفحة الرئيسية - الهيرو، الأقسام، عروض الفلاش، تجهيز العرايس |
| `shop.dc.html` | المتجر (Shop) | قائمة المنتجات مع فلاتر وترتيب |
| `product.dc.html` | صفحة المنتج (Product) | تفاصيل المنتج، ألوان، مواصفات، باندل |
| `cart.dc.html` | السلة (Cart) | عرض المنتجات في السلة، كوبون خصم |
| `checkout.dc.html` | إتمام الشراء (Checkout) | بيانات العميل، عنوان التوصيل، الدفع |
| `order-confirmed.dc.html` | تأكيد الطلب (Confirmation) | صفحة نجاح الطلب |
| `login.dc.html` | تسجيل الدخول (Login/Register) | دخول، حساب جديد، تاجر |
| `account.dc.html` | حسابي (Account) | طلباتي، عناويني، بياناتي، نقاط الولاء |

## المكونات المشتركة

| الملف | المكون |
|-------|--------|
| `Header.dc.html` | الهيدر (مشترك في كل الصفحات) |
| `Footer.dc.html` | الفوتر (مشترك في كل الصفحات) |

## الـ User Flow (المسار التفاعلي)

```
الرئيسية → المتجر → صفحة المنتج → السلة → إتمام الشراء → تأكيد الطلب
    ↕           ↕           ↕         ↕          ↕
تسجيل الدخول ← → حسابي
```

## كيف تفتح البروتوتايب

الملفات دي بصيغة DesignCompose (.dc.html) - افتحها في الأداة المناسبة.
